# Онлайн-магазин 

Проект представляет собой базовое веб-приложение на Django . Интерфейс страниц стилизован с помощью фреймворка Bootstrap.

## 🚀 Функционал
*   **Главная страница (Каталог):** Отображение списка доступных товаров в виде адаптивных карточек с автоматической обрезкой длинного описания до 100 символов для сохранения единого стиля интерфейса.
*   **Страница товара (Детализация):** Отдельная страница для каждого продукта с выводом полной информации (название, категория, детальное описание, цена и изображение) и возможностью возврата в каталог.
*   **Страница контактов:** Вывод контактных данных компании и интерактивной формы обратной связи с валидацией полей, защитой от ошибок и автоматическим сохранением сообщений в базу данных.
*   **Архитектура шаблонов (DRY):** Реализован сквозной базовый шаблон (`base.html`), содержащий общие стили, скрипты, шапку и подвал сайта. Выделен повторно используемый подшаблон (`header.html`) для динамического вывода приветствия.
*   **Маршрутизация (Routing):** Изолированная архитектура URL-адресов внутри приложения с использованием пространств имен (`namespace`). Настроены чистые URL-адреса вида `/products/<int:pk>/`.
*   **Управление данными (ORM):** Созданы модели продуктов (`Product`), категорий (`Category`) и сообщений обратной связи (`ContactMessage`) со связями `ForeignKey`.
*   **Панель администратора:** Настроена кастомная админка с фильтрацией по категориям, поиском по названию/описанию и выводом ключевых полей.
*   **Управление через фикстуры:** Реализовано сохранение и загрузка тестовых данных в формате JSON.
*   **Кастомные команды:** Добавлена консольная команда для быстрой очистки БД и перезаполнения её данными из фикстур.

## 🛠 Технологический стек
*   Python 3.12+
*   Django 6.x
*   PostgreSQL (СУБД)
*   Pillow (Работа с изображениями товаров)
*   IPython (Продвинутая интерактивная консоль)
*   python-dotenv (Безопасное хранение секретов)
*   Bootstrap 5 (Для стилизации)
*   Poetry (Управление зависимостями)

## Установка и запуск проекта

### 1. Клонирование репозитория и переход в папку
```bash
git clone <ссылка_на_репозиторий>
cd online-store-project
```

### 2. Установка зависимостей через Poetry
Убедитесь, что у вас установлен Poetry. Для установки окружения выполните:
```bash
poetry install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге проекта на основе шаблона `.env.sample` и заполните ваши доступы к PostgreSQL и секретный ключ Django:
```env
DB_NAME=имя_базы_данных
DB_USER=имя_пользователя
DB_PASSWORD=ваш_пароль
DB_HOST=127.0.0.1
DB_PORT=5432
SECRET_KEY=ваш_секретный_ключ
```

### 4. Активация виртуального окружения
```bash
poetry shell
```

### 5. Применение миграций базы данных
Создайте таблицы в СУБД PostgreSQL:
```bash
python manage.py migrate
```

### 6. Наполнение базы данных тестовыми данными
Запустите кастомную команду для автоматической очистки таблиц и загрузки актуальных фикстур:
```bash
python manage.py fill_db
```

### 7. Создание суперпользователя (для доступа в админку)
```bash
python manage.py createsuperuser
```

### 8. Запуск сервера разработки
```bash
python manage.py runserver
```

После запуска сервер будет доступен по адресу: `http://127.0.0`

## Маршруты 
*   `/` — Главная страница каталога (`name='home'`).
*   `/contacts/` — Страница с контактной информацией (`name='contacts'`).
*   `/admin/` — Панель администратора Django.
