# Онлайн-магазин 

Проект представляет собой базовое веб-приложение на Django . Интерфейс страниц стилизован с помощью фреймворка Bootstrap.

## Функционал
*   **Главная страница (Каталог):** отображение домашней страницы интернет-магазина.
*   **Страница контактов:** вывод контактных данных компании и формы обратной связи.
*   **Маршрутизация (Routing):** изолированная архитектура URL-адресов внутри приложения с использованием пространств имен (`namespace`).

## Технологический стек
*   Python 3.12+
*   Django 5.x / 6.x
*   Bootstrap 5 (для стилизации)
*   Poetry (управление зависимостями)

## Архитектура проекта
```text
online-store-project/
```

## Установка и запуск проекта

### 1. Клонирование репозитория и переход в папку
```bash
git clone <ссылка_на_репозиторий>
cd online-store-project
```

### 2. Установка зависимостей через Poetry
Убедитесь, что у вас установлен Poetry. Для установки окружения выполните:
```bash
poetry install
```

### 3. Активация виртуального окружения
```bash
poetry shell
```

### 4. Применение миграций базы данных
```bash
python manage.py migrate
```

### 5. Запуск сервера разработки
```bash
python manage.py runserver
```

После запуска сервер будет доступен по адресу: `http://127.0.0`

## Маршруты 
*   `/` — Главная страница каталога (`name='home'`).
*   `/contacts/` — Страница с контактной информацией (`name='contacts'`).
